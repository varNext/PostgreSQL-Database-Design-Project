# PostgreSQL-Database-Design-Project
Практические учебные работы по PostgreSQL

# Техническое задание
Практическое задание связано с проектированием схемы базы данных для аналитики.Основная задача состоит в создании оптимизированной структуры БД, способной эффективно работать с большими объемами данных (более 10 миллионов записей), поддерживать полнотекстовый поиск и секционирование таблиц. Результатом данного практического задания являются: скрипты создания базы данных, хранимая процедура (генератор) для ее заполнения, анализ плана выполнения запроса.

## Требования к БД
✓ Одна таблица (Item transportation) должна содержать не меньше 10 млн. записей. 
✓ Другая таблица (Shipped Item), связанная с первой, должна содержать не меньше 1 млн. записей.
✓ Остальные таблицы должны содержать по 5-10 записей.
✓ В одной из таблиц с количеством записей 10 млн. используется колонка Comment с человекочитаемым текстом (не псевдопоследовательность), по которой далее будет необходимо настроить полнотекстовый поиск. Объем выборки ~1000 слов.


## Особенности работы
• регистрация/активация расширения python в СУБД создается командой CREATE
• шаблон объявления функции/процедуры в PostgreSQL
CREATE FUNCTION имя_функции (аргументы)
RETURNS возвращаемый_тип
AS $$
 (Тело функции на PL/Python)
$$ LANGUAGE plpython3u;
Тело функции содержит просто скрипт на языке Python. Когда вызывается функция, её аргументы передаются в виде элементов списка args; именованные аргументы
также передаются скрипту Python как обычные переменные.
• нельзя использовать СУБД драйвер python psycopg2.
• генерация должна происходить прямо в процедуре/функции. Для оптимизации скорости все ограничения БД (первичные/внешние ключи, ограничения типа)
нужно добавлять в таблицы после окончания генерации. Сами строки для вставки генерировать нужно блоками (1000-100000). Если вставлять по одной строке, будет
долго из-за поддержки целостности.
