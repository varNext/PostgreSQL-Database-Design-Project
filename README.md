# PostgreSQL-Database-Design-Project
Практическая работа по PostgreSQL

# Практическое задание 
## Постановка задачи
Основная задача состоит в создании оптимизированной структуры БД, способной эффективно работать с большими объемами данных, поддерживать полнотекстовый поиск и секционирование таблиц. Результатом данного практического задания являются: скрипты создания базы данных, хранимая процедура (генератор) для ее заполнения.

Требуется создать БД для кооперативов с таблицами перевозок/отгрузок, наполнить её большим объёмом тестовых данных (10+ млн перевозок, 1+ млн отгрузок) и подготовить базу для экспериментов по оптимизации запросов (индексы, JOIN, полнотекстовый поиск).


## Требования к БД
- Одна таблица (Item transportation) должна содержать не меньше 10 млн. записей. 
- Другая таблица (Shipped Item), связанная с первой, должна содержать не меньше 1 млн. записей.
- Остальные таблицы должны содержать по 5-10 записей.
- В одной из таблиц с количеством записей 10 млн. используется колонка Comment с человекочитаемым текстом, по которой далее будет необходимо настроить полнотекстовый поиск. Объем выборки ~1000 слов.
- Для наполнения БД используется хранимая функция на языке `plpython3u`, генерирующая реалистичные связанные данные пакетами.
